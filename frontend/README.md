# Haven KNUST — Frontend

React + Vite single-page app. See the [project root README](../README.md) for
the full setup guide, architecture overview, and demo credentials.

Quick start (after the backend is running):

```bash
npm install
npm run dev
```

Runs at http://localhost:5173 and talks to the backend at the URL set in
`.env` (`VITE_API_URL`, defaults to `http://localhost:4000/api`).
